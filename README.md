# Financial Transaction Stream Merger ($k$-Way Merge vs. Pairwise Merge)

## 📌 Project Overview
This repository contains the implementation and performance analysis of merging multiple sorted financial transaction lists using two different approaches in C:
1. **$k$-Way Merge using a Min-Heap** (Priority Queue)
2. **Simple Pairwise Merging Approach**

Given three sorted transaction lists:
* $L_1 = [10, 30, 50, 70]$
* $L_2 = [20, 40, 60, 80]$
* $L_3 = [15, 35, 55, 75]$

The project compares their execution steps, time/space complexities, number of comparisons, and scalability.
